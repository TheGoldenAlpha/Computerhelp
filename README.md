# Computerhelp
## DomainCheck
`DomainCheck.exe` herunterladen (Releases → "DomainCheck (latest)" oder Actions → Artifact), starten, Browser öffnet sich auf http://127.0.0.1:8765.
Domains einfügen, Keywords (Default `einstein`) setzen, Start. Export als CSV/JSON. Ohne exe: `python domaincheck/domaincheck.py` (nur Standardbibliothek).
